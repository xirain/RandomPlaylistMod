Beat Saber · 1.44.0

RandomPlaylistMod

设定时长，从多个歌单里随机选歌、连续不间断播放。从此告别「下一首点什么」的纠结。

下载 v2.3.3 GitHub 仓库
核心功能

为「随便来几首」而生

⏱️

时长设定

预设 30 分钟 / 1 小时 / 2 小时，或自定义 1–120 分钟，时间到自动结束会话。

📜

多歌单池

勾选多个 Playlist Manager 歌单组成歌曲池，内置 OST 与「所有自定义歌曲」虚拟歌单。

🎯

NPS 速度筛选

按 Notes Per Second 过滤，体感对应 Hard / Expert 等难度（数据来自 SongDetailsCache）。

🔀

智能随机

Fisher-Yates 洗牌保证随机性，自动预估歌曲数量与总时长，不重复不冷场。

▶️

无缝连播

一曲结束自动切下一首；加载失败智能跳过，会话不中断。

🛡️

不死模式

可在主界面设置中启用 No Fail，安心刷歌、轻松热身。

使用方式

四步开刷

1
进入 MODS 面板
主菜单左侧点击 MODS，找到 Random Playlist。
2
设定筛选与时长
选择 NPS 速度区间，再选播放时长（预设或自定义分钟数）。
3
勾选歌单
在歌单列表中勾选目标歌单，含 OST / 自定义歌曲虚拟歌单。
4
Start Session
点击开始；播放中可随时 End Session 提前结束。
前置依赖

安装前请备齐

BSIPA 4.1+ Playlist Manager SongCore 3.9+ SiraUtil 3.0+ BSML 1.6+ SongDetailsCache
将下载的 RandomPlaylistMod.dll 放入 Beat Saber 实例的 Plugins/ 目录，启动游戏即自动加载。本模组针对 Beat Saber 1.44.0 开发（测试环境：Pico 4 Ultra 串流）。
